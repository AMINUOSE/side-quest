# Side Quest

A small static site by Zekai Chen: a landing page, a playable 5×5 mini crossword, an about page, and a contact page. Built for CS5610 (Project 1).

## Pages

- `index.html` – landing page
- `game.html` – mini crossword
- `about.html` – education, projects, experience
- `contact.html` – how to reach me

## Structure

- `css/base.css` – shared tokens, layout, navbar, footer
- `css/<page>.css` – page-specific styles
- `images/` – SVG logo and illustration, portrait photo
